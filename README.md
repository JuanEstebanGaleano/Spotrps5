# Spotrps5

Spotify Connect para una PS5 con jailbreak: la consola aparece como un altavoz en la app de Spotify de tu móvil
(requiere cuenta Premium). Proyecto no oficial, sin relación con Spotify ni Sony.

> **Estado: preparando la base.** Este repositorio parte del loader de
> [PokeMMO-Prospero](https://github.com/Shabbypenguin/PokeMMO-Prospero) (GPL-3.0), que ejecuta binarios Linux x86-64
> en la PS5. El plan es ejecutar [librespot](https://github.com/librespot-org/librespot) con él. Ver
> [docs/spotify-plan.md](docs/spotify-plan.md).

Probado como base en firmware 12.40; el objetivo de este proyecto es el **13.60** (Relapse + kstuff-lite +
ShadowMountPlus). El loader original arranca en 13.60.
